# XR Knee SC Bone — Subchondral Bone Texture / Integrity

Measurements of **subchondral bone integrity** (trabecular texture) from OAI knee radiographs, produced by the Duke Image Analysis Laboratory for the FNIH Osteoarthritis Biomarkers Consortium project.

> **Role in the thesis.** Not used. Retained as part of the complete OAI image-assessment documentation set.

## What is in this folder

| File pattern | Content |
|---|---|
| `kXR_FNIH_BTI_Duke00.txt`, `_01.txt`, `_03.txt` | Bone-texture measurements at baseline, 12 and 24 months |
| `*_Contents.pdf` / `*_Stats.pdf` | Data dictionary and summary statistics for the matching `.txt` |
| `kXR_FNIH_BTI_Duke_Descrip.pdf` | Methods: *Measurement of Subchondral Bone Integrity from Knee Radiographs* |

Read-only source files; do not edit in place.
