# XR Hip Semi-Quant — Central Readings of Hip Radiographs

Semi-quantitative readings of **hip** osteoarthritis features from the OAI pelvic radiographs (UCSF reading project), at baseline and follow-up visits, per hip side.

> **Role in the thesis.** Not used. The thesis concerns knee grading only; the hip readings are kept so that the `assessments/` folder mirrors the complete OAI image-assessment documentation that was obtained under the Data Use Agreement.

## What is in this folder

| File pattern | Content |
|---|---|
| `hxr_sq00.txt`, `hxr_sq01.txt`, `hxr_sq06.txt` | Hip readings at baseline, 12 months and 72 months |
| `hxr_sq_ucsf00/01/06.txt` | UCSF reading-project files for the same visits |
| `hxr_sq_summary.txt` | Cross-visit summary table |
| `*_Contents.pdf` / `*_Stats.pdf` | Data dictionary and summary statistics for the matching `.txt` |
| `hxr_sq_Description.pdf` | Methods: *Central Reading of X-rays for Individual Radiographic Features of Hip OA* |

Read-only source files; do not edit in place.
