# Novel Experiments: Provenance, Preprocessing, and Concept-Level Transfer

This folder contains the thesis experiments that investigate why cross-cohort
knee osteoarthritis (KOA) grading can fail. They are not another model search:
they audit dataset provenance, isolate preprocessing as a paired intervention,
and separate image-to-finding perception from finding-to-grade policy.

> **Status:** core forensic contribution. These notebooks explain the provenance
> and preprocessing boundaries that shape the final protected OAI-to-NHANES
> analysis; they do not replace its frozen evaluation protocol.

## Research Questions

1. Is the Mendeley knee dataset an independent external cohort for OAI-based
   evaluation, or is it derived from the same OAI knees?
2. Can changing only the order of CLAHE and resizing alter a frozen model's KL
   grade or predicted radiographic findings for the same knee?
3. Does this preprocessing sensitivity replicate on genuinely independent
   NHANES III images?
4. Can a concept-bottleneck representation distinguish instability in
   `P(findings | image)` from a cohort-specific `P(KL grade | findings)` policy?

## Notebooks

| Notebook | Purpose | Main output |
| --- | --- | --- |
| `preprocess_variants_inference (1).ipynb` | Runs one frozen multi-task model on the same OAI knees under four preprocessing variants: reference order, MRKR order, double CLAHE, and no CLAHE. | `preprocess_variants_findings.csv` |
| `preprocess_effect_analysis (1).ipynb` | Measures paired grade and clinical-finding disagreement, accuracy/QWK changes, and systematic bias caused by preprocessing alone on OAI. | Figures and summary tables from the OAI variant file |
| `preprocess_variants_nhanes.ipynb` | Repeats the four-variant inference experiment on a sampled, genuinely independent NHANES III cohort using the same frozen checkpoint. | `nhanes_preprocess_variants_findings.csv` |
| `preprocess_crosscohort_analysis.ipynb` | Compares the paired OAI and NHANES results to test whether preprocessing sensitivity is cross-institutional rather than OAI-specific. | Cross-cohort summary table and figures |
| `knee_oa_cbm_ceiling.ipynb` | Audits Mendeley/OAI provenance, measures same-knee pipeline instability, tests the perception-versus-policy hypothesis, evaluates few-label policy adaptation, and performs a concept intervention. | Provenance, instability, adaptation, and intervention analyses |

## Run Order

Run the preprocessing study in this order:

1. `preprocess_variants_inference (1).ipynb`
2. `preprocess_effect_analysis (1).ipynb`
3. `preprocess_variants_nhanes.ipynb`
4. `preprocess_crosscohort_analysis.ipynb`

`knee_oa_cbm_ceiling.ipynb` is a separate study. It requires the per-cohort
`*_findings.csv` outputs generated by the multi-task trainer before it can run.

## Experimental Controls

The preprocessing experiments hold the model checkpoint, anatomy, and label
fixed while changing only image preprocessing. Their paired disagreement is
therefore attributable to the preprocessing intervention, not patient,
scanner, prevalence, or grader differences.

The concept-bottleneck study parses subject-and-side identifiers, checks label
agreement, and uses NHANES and MRKR as negative controls for overlap detection.
If Mendeley and OAI share the same knees, Mendeley must be treated as an
OAI-derived control for pipeline sensitivity, not as independent external
validation.

## Environment and Data

These notebooks are designed for Google Colab with a GPU and the thesis
training libraries available under `/content/drive/MyDrive/Master Thesis/`.
They load the frozen `mt_mendeley_seed0` multi-task checkpoint by default and
write generated CSV files to the Google Drive `scope3_mt/results` directory.
They do not retrain the model.

The NHANES experiment downloads source TIFF films from the CDC FTP endpoint.
Rerunning it may therefore take substantial time and depends on network access.

For new runs, write all generated files to a reproducible Google Drive project
location (the project convention is `/content/drive/MyDrive/oai/`), never to
ephemeral `/content` storage. Historical notebook paths may retain older Drive
subdirectory names.

## Interpretation Boundaries

- Treat preprocessing disagreement as a validated model-failure signal, not as
  a universal out-of-distribution detector unless separately evaluated as one.
- Treat a concept intervention as evidence about where a model's error enters;
  it does not by itself establish universal policy transportability.
- Report provenance and overlap results with the source documentation and
  image-level evidence used for the final analysis.
