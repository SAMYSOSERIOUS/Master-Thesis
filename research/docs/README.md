# docs

Documentation and generated reports for the thesis pipeline (no executable notebooks).

This folder holds written outputs — progress reports, result summaries and
generated metadata — that accompany the experiments in the sibling folders.
Unlike the other folders, it contains no `.ipynb` files and therefore no methods
of its own; it is the place where results produced by `pipeline_v1` and the
analysis notebooks are recorded in human-readable form.

## Documentation Role

Treat reports here as supporting records for the exploratory research workspace.
The current protected workflow and its acceptance evidence are documented in
[`../../Final Notebook/`](../../Final%20Notebook/). When a report discusses a
historical Mendeley fold, interpret it with the provenance finding in
[`../novel/`](../novel/) rather than as independent OAI external validation.

## Contents

- `koa_results.docx` — written summary of knee-osteoarthritis grading results.

## Artifact Handling

Keep regenerated reports, tables, and figures on Google Drive. This folder
tracks documentation and small metadata only; it is not a destination for large
generated datasets, checkpoints, or temporary Colab output.
